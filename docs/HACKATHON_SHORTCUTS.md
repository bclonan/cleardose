# Hackathon shortcuts

Open `/#/shortcuts` or the floating **Demo shortcuts** CTA. The workbench is a judge-facing control surface, not an autonomous agent.

## Real calls versus the visual analog

Each chain and each step displays a natural-language **Say** prompt in full. **Copy this exact prompt** uses the shared clipboard fallback, while **Read aloud** supports voice-mode demos. The agent decides which registered tools to call and remains subject to tool validation and human-review gates; the visible prompt remains usable even when clipboard or speech APIs are unavailable.

**Run visual analog** never claims to be that agent. It creates `machine.dynamic.shortcut-<id>.v1`, records one deterministic `SHORTCUT_STEP_*_VISIBLE` event per displayed step, and pauses at `human_review`. The viewer shows the real locally persisted flow and context generated by the simulation.

## Add a shortcut

1. Add a frozen record to `src/services/api/shortcuts/hackathonShortcuts.js`.
2. Use a kebab-case shortcut id and declare `mode`, `category`, `duration`, `summary`, `prompt`, and `scope`.
3. Scope requires `role`, `situation`, and `step`.
4. Every step must reference an existing `capabilityId` and contain a short visible prompt.
5. Run `npm run evals:contracts`; the validator rejects unknown capabilities, duplicate names, or invalid machine contracts.

## Human-controlled memory

The memory workbench turns reviewed facts, decisions, next steps, and flow references into structured JSON plus Markdown. Preparing a packet does not copy, save, upload, or retain it in an external model. **Copy for my agent** uses the clipboard. **Save Markdown** uses the File System Access picker in a secure supporting browser and a download fallback elsewhere.
